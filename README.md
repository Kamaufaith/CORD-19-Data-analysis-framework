# CORD-19 Research Analysis Framework
## Overview
A python based framework for analyzing, cleaning and extracting data from the Covid-19 Open Research Dataset (CORD-19), based on a small sample metadata.csv file from the dataset. Provides researchers with tools for processing, analyzing and visualising COVID-19 research at scale.
## Features
- Data analysis and visualisation
- Data cleaning
- Streamlit application
## Visualisation
Created a streamlit application to display the visualizations in the app and show a sample of the data.
### Output
The framework generates pdf/png figures
## Prerequisites
- Python 3.7+
- pandas (data manipulation)
- matplotlib/seaborn (visualization) and graph files.
- Streamlit (web application)
